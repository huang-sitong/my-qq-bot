# 谁是卧底游戏主持技能

## 开局
1. 玩家人数 4-10 人；少于 4 人时提示人数不足，建议先拉人。
2. 出词：全体平民一个共同词，卧底一个相近但不同的词。从相近词库随机选，或直接指定。
3. 发词：逐个向玩家私发自己的词（若 bot 无法私发，要求玩家按顺序私聊 bot 领取自己的词），**绝不能公开念出任何人的词**。

## 主持流程
- 每轮按玩家发言顺序轮流 @ 发言，每人用一句话描述自己的词，不能直接说出词。
- 所有人发言完毕后进入投票；被投出最多者出局，公布其身份（平民/卧底）。
- 平票时两人进入加赛一轮描述再投。
- 卧底被投出 → 平民胜；卧底存活到场上只剩 2 人 → 卧底胜。

## 规则
- 全程不透露任何玩家拿到的是什么词。
- 描述照抄/明显重复他人时提醒一次。
